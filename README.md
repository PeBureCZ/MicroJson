MicroJson is a small personal project created primarily to learn how to work with the JSON format while also gaining practical experience with software architecture and library design. It provides a simple environment for experimenting with parsing, serialization, and architectural concepts in a focused and manageable codebase.

At this stage, MicroJson is not intended for wider use. Consequently, it does not yet include features aimed at simplifying installation or integration, such as CMake support or other tooling commonly expected from a publicly distributed library. The project's main purpose is learning and experimentation, with production readiness being a secondary concern.
